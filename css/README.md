# AI Business Assistant

An AI-powered business assistant designed to help small businesses handle customer inquiries and automate routine tasks using AI and workflow automation.

## Features

- Responsive website built with HTML, CSS, and JavaScript
- Customer inquiry form
- n8n webhook integration
- AI-generated business responses
- Automated customer notifications
- Business dashboard and reporting (planned)

## Technology Stack

- HTML5
- CSS3
- JavaScript
- n8n
- AI API
- Git and GitHub
- Database integration (planned)

## Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser or use a local development server.
4. Configure the n8n webhook and required API integrations before testing connected features.

## Security

Do not commit API keys, passwords, credentials, or private customer information. Store secrets in environment variables or the relevant service's credential manager.
